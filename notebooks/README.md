# Jupyter Notebooks

This directory contains interactive Jupyter notebooks for hands-on learning and exercises.

## How to Use

1. Make sure you have installed all requirements:
   ```bash
   pip install -r requirements.txt
   ```

2. Start Jupyter Lab or Jupyter Notebook:
   ```bash
   jupyter lab
   # or
   jupyter notebook
   ```

3. Navigate to the desired notebook and follow the instructions within.

## Notebook Topics

Notebooks are organized by topic and difficulty:

- **Introductory Notebooks**: Basic Python, NumPy, Pandas
- **Data Processing**: Working with Earth system datasets
- **Machine Learning**: Classification, regression, clustering
- **Deep Learning**: Neural networks, CNNs, RNNs
- **Geospatial Analysis**: Working with spatial data
- **Time Series**: Analyzing temporal Earth system data
- **Projects**: End-to-end projects combining multiple concepts

## Tips

- Save your work frequently
- Create a copy of notebooks before modifying them
- Use markdown cells to document your analysis
- Check the official documentation for libraries when stuck
