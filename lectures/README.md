# Lectures

This directory contains lecture materials for CVEN 5833.

## Structure

Each lecture is organized by week/topic:

- `01_introduction/` - Introduction to AI for Earth System Science
- `02_python_basics/` - Python Programming Fundamentals
- `03_data_processing/` - Data Processing and Feature Engineering
- `04_supervised_learning/` - Supervised Learning Methods
- `05_deep_learning/` - Deep Learning Fundamentals
- `06_time_series/` - Time Series Analysis
- `07_geospatial/` - Geospatial Data Analysis
- `08_climate_modeling/` - Climate Modeling with AI
- `09_hydrology/` - Hydrological Predictions
- `10_monitoring/` - Environmental Monitoring

## Format

Lecture materials may include:
- PDF slides
- Jupyter notebooks with code examples
- Supplementary reading materials
- Links to external resources
