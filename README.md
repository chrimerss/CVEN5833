# CVEN 5833: AI for Earth System Science and Engineering

This repository contains teaching materials for CVEN 5833: AI for Earth System Science and Engineering at CU Boulder.

## Course Description

This course explores the application of artificial intelligence and machine learning techniques to Earth system science and engineering problems. Students will learn how to apply state-of-the-art AI methods to analyze, model, and predict environmental phenomena.

## Repository Structure

```
CVEN5833/
├── lectures/          # Lecture slides and materials
├── notebooks/         # Jupyter notebooks for hands-on exercises
├── assignments/       # Homework assignments and projects
├── data/             # Sample datasets for exercises
├── resources/        # Additional learning resources and references
└── README.md         # This file
```

## Prerequisites

- Python 3.8 or higher
- Basic understanding of programming
- Familiarity with linear algebra and calculus
- Basic statistics knowledge

## Getting Started

### Installation

1. Clone this repository:
```bash
git clone https://github.com/chrimerss/CVEN5833.git
cd CVEN5833
```

2. Create a virtual environment (recommended):
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install required packages:
```bash
pip install -r requirements.txt
```

### Running Jupyter Notebooks

To run the course notebooks:
```bash
jupyter notebook
```

Navigate to the `notebooks/` directory to access the interactive exercises.
