# Assignments

This directory contains homework assignments and course projects.

## Structure

Assignments are organized by number:

- `assignment_01/` - Introduction to Python and Data Analysis
- `assignment_02/` - Data Processing and Visualization
- `assignment_03/` - Supervised Learning Applications
- `assignment_04/` - Deep Learning for Earth Systems
- `assignment_05/` - Final Project

## Submission Guidelines

1. Complete all tasks in the assignment notebook or script
2. Include clear documentation and comments
3. Test your code before submission
4. Follow the naming convention: `lastname_firstname_assignmentX.ipynb`
5. Submit via the course management system by the due date

## Grading Criteria

Assignments are typically graded on:
- Correctness (40%): Does the code produce correct results?
- Code Quality (20%): Is the code well-organized and readable?
- Documentation (20%): Are explanations clear and thorough?
- Analysis (20%): Are results properly interpreted and discussed?

## Academic Integrity

- You may discuss concepts with classmates
- All submitted work must be your own
- Cite any external resources or code used
- Plagiarism will result in a zero on the assignment

## Getting Help

- Attend office hours
- Post questions on the course forum
- Review lecture materials and notebooks
- Consult the course textbook and documentation
